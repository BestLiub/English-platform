## 三、背单词

进入模块后，顶部可以切换两种模式。两种模式的数据完全隔离。

### 3.1 计划模式（沿用 v0.1，补一个上限）

- 每日新词数：可调（已有）
- **每日复习上限：可调（新增）**。现在是"所有到期卡片全上"，没有上限；改成取到期的前 N 张，N 用设置里的值，默认 100

队列构成不变：到期复习在前，新词补足。调度仍然走 FSRS。

### 3.2 沉浸模式（本轮重点）

**循环**

```
从「还没掌握」的词里随机抽一个
  ├─ 点「跳过」    → 这个词标记为已掌握，从池子里永久移除，不进复习队列
  └─ 点「显示释义」→ 展示释义，放回池子，之后还会被抽到
继续，直到池子里没有词 → 显示"全部背完" → 提供「重新开始」
```

**关键行为**

| 行为 | 结果 |
|---|---|
| 跳过 | 该词在沉浸模式内永久不再出现；**不影响**计划模式的任何状态 |
| 显示释义 | 该词留在池子里，可以再次被抽到 |
| 中途退出 | 进度保留，下次进入接着刷 |
| 全部掌握 | 显示完成页，可以清空沉浸模式的全部进度重新开始 |

**随机算法**

每次抽词：

1. 候选池 = 当前词库（如六级 5700 词）中，未被标记为已掌握的词
2. 排除最近抽过的 K 个词，`K = min(50, 候选池数量 / 3)` 向下取整
3. 在剩下的词里均匀随机取一个
4. 若排除后为空（候选池 ≤ 3 时会发生），取 K = 0，不排除

这样六级词库是"隔 50 个才会再见"，三个词的池子至少隔 1 个，不会出现抽不出词的死锁。

**进度**

显示 `已掌握 X / 总数 Y`，X 只统计点过跳过的词。

**我的判断**：内容区沿用计划模式的卡片组件（正面单词 + 音标 + 朗读，翻面看释义），两个模式的卡片长得一样，用户不用重新学。

但卡片里现在印着两个只属于计划模式的东西：左上角的「新词 / 复习」标签，和背面的「1 不认识 · 2 记忆模糊」提示。沉浸模式没有新词复习之分、也没有评分步骤，所以要给卡片加两个可选开关（`showBadge`、`showRatingHint`），沉浸模式传 false。默认值保持现在的行为，计划模式不受影响。

## 五、个人页

统计 + 设置合并成一页。

- **统计**：沿用现有内容（累计复习、已学单词、正确率、每日复习量图表）
- **设置**：每日新词数、每日复习上限、生词注释策略、当前词库

**我的判断**：沉浸模式的数据不计入这些统计。它和计划模式是两套东西，混在一起算会让"正确率"这类指标失真。沉浸模式在自己的页面里显示自己的进度。

## 六、数据模型

### 新增表 `immersion_word`

| 字段 | 说明 |
|---|---|
| id | 主键 |
| user_id | 预留给将来的账号体系，现在固定 1 |
| word_id | 外键 → word.id |
| status | `seen`（出现过、未掌握）/ `mastered`（点过跳过） |
| last_seen_at | 最近一次被抽到的时间，用于防重复窗口 |

约束：`(user_id, word_id)` 唯一。

**`seen` 的语义是"出现过、还没掌握"，不是"看过释义"**（我的判断）。抽词时就会写入这一行，因为防重复窗口必须覆盖"抽到过但没来得及操作"的词——否则抽到一半关掉应用，下次进来立刻又是同一个词。这意味着抽词接口是有副作用的，所以它必须是 POST 而不是 GET。

**为什么单独一张表**：沉浸模式和计划模式的状态必须隔离。共用 `user_word` 会让"跳过"污染 FSRS 队列，这正是要避免的。

### 现有表

不改结构。`user_word.status`（上一轮加的 `known`）继续只服务计划模式。

## 七、接口草案

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/immersion/next` | `{wordbook}`，抽下一个词（会写 `seen` 记录），同时返回进度 |
| POST | `/api/immersion/reveal` | `{word_id}`，返回释义，只更新 `last_seen_at` |
| POST | `/api/immersion/skip` | `{word_id}`，标记为 `mastered` |
| POST | `/api/immersion/reset` | `{wordbook}`，**只清空该词库的沉浸进度**（我的判断：这是破坏性操作，范围越小越好） |
| GET | `/api/immersion/stats?wordbook=cet6` | `{total, mastered, remaining}` |

`/api/study/plan` 增加 `review_limit` 参数。

## 九、验收标准

1. 主页三个入口都能点进去，没有死链接
2. 沉浸模式：选中六级 → 抽词 → 跳过 → 该词不再出现；点显示释义 → 该词若干次后再次出现
3. 沉浸模式和计划模式的状态互不影响：沉浸模式跳过的词，计划模式该推的新词照旧
4. 中途关掉应用再打开，沉浸模式进度还在
5. 全部跳过之后出现完成页，能重新开始
6. 计划模式的每日复习上限生效：设置 50，当天到期 200 张只出 50 张
